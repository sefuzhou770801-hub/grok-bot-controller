运行模式

Stack-chan 的主要运行方式有三种。“对话响应”使用 OpenAI / Gemini / XiaoZhi 之一进行对话；“JTTS 随机语音”只在空闲时播放语音； “麦克风口型”只根据麦克风输入驱动嘴部。 保存并重启后生效。

留空则不修改当前值

设备名称 (BLE / mDNS)

用于 BLE 广播名称和 mDNS 主机名。留空则自动生成 (Stackchan-XXXXXX)。 mDNS 会规整为英数字和连字符。保存并重启后生效。

密码认证

设置后，此设置页面 (Wi-Fi) 和 BLE 都需要认证。 保存空值会恢复为无认证（兼容当前行为）。HTTP 使用 Basic Auth，BLE 会 将密码混入加密密钥。保存并重启后生效。

脸部绘制 DSL (Avatar)

扬声器音量

对内置扬声器、Module Audio、Atomic Echo Base 的输出都有效。 移动滑块会 立即生效 并自动保存（无需重启）。 100% = 每块开发板的出厂默认值，200% 为增强。

jtts 试发声

输入平假名 / 片假名后点击“发声”，jtts 会朗读。 汉字和英文字母不会被转换，请直接输入假名读音。 适合检查音量和音频输出。

音频输出

选择音频输出位置。“自动”会在检测到 M5 Module Audio 时优先使用它， 未安装时使用内置扬声器。“内置”和“Module Audio”为强制指定 （未安装 Module Audio 却选择它时会回退到内置扬声器）。 保存并重启后生效。

触摸操作

AI 回复播放中，点击头像画面（头部）可中断回复。触摸传感器较敏感，容易误触，所以默认关闭。摸头手势（前→中→后连续触摸）与此开关无关，始终启用。保存并重启后生效。

设备功能开关

在头像画面左上角显示电量（保存并重启后生效）

是否在启动后播放 C5–E5–G5（扬声器检查音）。关闭后静音启动（保存并重启后生效）

关闭后不会打开舵机电源，也不会启动舵机任务（保存并重启后生效）。这与操作画面的脱力/恢复开关不同，本项会持久保存到 NVS。

头像嘴部张开时 LED 会响应（对话播放、jtts 发声、麦克风口型都有效）。关闭时保持设置亮度。保存并重启后生效。

选择开启时的控制方式。“亮度”表示嘴巴越张开，LED 整体越亮； “电平表”会把猫耳三角形（LED1 = 底边，LED5 = 顶点） 当作 5 段条形图点亮。保存并重启后生效。

舵机原点与可动范围（Takao base 等自制底座）

舵机安装方向和可动范围会随底座基板而不同。请设置原点 (0..1023) 与可动范围（度）， 点击“保存并重启”后生效。默认值为 M5 base。

开启范围设置模式后，舵机会脱力，可以记录手动移动到的位置。 请在中心位置点击“记录 Yaw 原点”，在左端点击“记录 Yaw 最小”，在右端点击“记录 Yaw 最大”。 记录值会填入上方输入框，最后点击“保存并重启”确认。

固件更新 (OTA)

选择本地 firmware.bin 后点击“写入”，会把新固件 写入另一个分区并重启。Wi-Fi 方式明显快于 BLE。

获取最新 release 的步骤（iPhone / AP 模式也可）
  1. 用 Safari ciniml.github.io/stackchan-idf 打开。
    （即使 AP 模式下 Wi-Fi 无法连接互联网，iOS 也会自动回退到蜂窝网络。若无法连接，请先关闭一次 Wi-Fi 再重试。）
  2. 下载对应开发板的 firmware-vX.Y.Z-<board>.zip
  3. 在“文件”App 中点击 ZIP 解压，其中的 stackchan_idf.bin 就是 OTA payload 本体
  4. （AP 模式时）连接设备的 AP，再重新打开本页面
  5. 在上方“选择文件”中选择 stackchan_idf.bin，然后点击“写入”

※ 请不要选择 firmware-vX.Y.Z-<board>.bin， 请改选 stackchan_idf.bin。前者是 bootloader + 分区表 + app 的合并镜像（用于 USB 首次烧录），不能用于 OTA。

直接从 release 获取（device side fetch）

设备通过 STA 从 GitHub Pages 获取对应自己的构建并 执行 OTA。AP 模式中只要 STA 已连接也可工作 (APSTA)。如果 STA 断开会报错，请改用上方“本地文件”。

从下拉列表选择后会填入右侧文本框，也可以手动输入（未来 tag / 特殊 build）。 开发板识别（cores3 / atoms3r / atoms3 / stopwatch）由设备自动完成。 进度会显示在下方状态栏。
